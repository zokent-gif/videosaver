# Video Saver

Простое Android-приложение в стиле Material You для сохранения видео и аудио по ссылке для **личного** использования. Создано при помощи ИИ Claude (Anthropic).

Вставляете ссылку, выбираете формат, и файл сохраняется в галерею (видео) или в папку с музыкой (аудио).

## Возможности
- Вставка ссылки кнопкой или через «Поделиться» из другого приложения
- Превью: картинка, название и длительность
- Форматы: MP4, WEBM, MKV, MP3, M4A
- История загрузок с очисткой одним нажатием
- Динамические цвета Material You (Android 12+)
- Работает на yt-dlp, поддерживает множество сайтов
- Без рекламы и аналитики

## Как пользоваться
1. Скопируйте ссылку на видео
2. Откройте Video Saver и вставьте ссылку
3. Выберите формат и нажмите «Скачать»
4. Файл появится в галерее, в альбоме VideoSaver

## Установка
Скачайте последний APK в разделе **Releases** справа. Нужен Android 8.0 или новее. Новые версии ставятся поверх старой.

## Ограничения
- Некоторые сайты (в том числе YouTube) могут блокировать загрузку
- Платные, закрытые и возрастные видео могут не скачиваться
